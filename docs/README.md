# Care Connect Documentation

Welcome to the Care Connect project documentation. This folder serves as the single source of truth for architecture, design principles, product requirements, and technical decisions.

## Directory Structure

* [**architecture/**](./architecture/) - System blueprints, component flows, and future backend architecture specifications.
* [**design/**](./design/) - Brand design tokens, color palettes, typography scale, and accessibility guidelines.
* [**requirements/**](./requirements/) - Product scopes, guardrails, and checklists:
  * [`scope-guardrails.md`](./requirements/scope-guardrails.md) - P0, P1, P2, and Out of Scope boundaries.
  * [`client-presentation-checklist.md`](./requirements/client-presentation-checklist.md) - Quality and polish criteria for the presentation prototype.
  * [`deferred.md`](./requirements/deferred.md) - Log of features intentionally deferred to future development phases.
* [**decisions/**](./decisions/) - Architecture Decision Records (ADRs):
  * [`001-frontend-first.md`](./decisions/001-frontend-first.md) - Rationale for developing the frontend prototype before the backend.
